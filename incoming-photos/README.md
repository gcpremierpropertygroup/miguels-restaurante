## What makes these work

- **Wide slots** (3, 5): room-wide shots. The dining room with people in it at
  a busy hour; the private room set for a party.
- **Tall slots** (2, 4, 6): closer, human moments. Someone mid-meal, a table
  raising glasses, a full table in the private room.
- Shoot in the light the room actually has. The site renders these dark with a
  gradient over the bottom third, so detail down there gets lost anyway.
- Faces need permission. If a guest is recognisable, get their OK before it goes
  on the site.
